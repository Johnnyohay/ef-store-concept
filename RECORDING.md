# Backup walkthrough: how to record it (60–90 s)

Record this the night before the pitch. If the live demo fails, play the video.

## Setup (2 min)
1. `npm run build && npm start` (serves http://localhost:3000). Turn Wi-Fi off to prove it works offline.
2. Chrome → open DevTools (Cmd+Opt+I) → device toolbar (Cmd+Shift+M) → **iPhone 14 Pro (393 px)**. Close DevTools' side panel so only the phone frame shows, or use a real phone (below).
3. Open `/demo` in a second tab and click **Reset counters**.
4. Hide the bookmarks bar (Cmd+Shift+B). Set zoom to 100%.

## Record
- **Mac:** Cmd+Shift+5 → "Record Selected Portion" → drag around the phone frame → Record. Stop from the menu bar.
- **Real iPhone (looks best):** Control Center → Screen Recording. Open `http://<your-mac-ip>:3000` on the same network *before* turning Wi-Fi off, or run on the Mac and mirror with QuickTime (File → New Movie Recording → pick the iPhone as camera).

## Script (about 80 s)
| Time | Do | Say (optional voice-over) |
|---|---|---|
| 0–8 s | Home, don't scroll | "Five seconds: what is it, who is it for." |
| 8–20 s | Scroll: three dates, red Rand block, "Who this is for" | "Story first. 1965, Lund. 1994, Rand. Today." |
| 20–45 s | Tap **Read how it happened** → scroll `/rand` slowly so each option slides in | "He promised one perfect logo. For EF, he drew several." |
| 45–60 s | Tap an option → product page: pick color, tap **M**, show **Size guide** link, shipping + returns | "Round price. Size buttons. Shipping and returns right here." |
| 60–70 s | **Add to bag** → Checkout → **Place demo order** → "This is a demo." | |
| 70–80 s | Menu → Shop by EF Business → Hult concept | "And the missing piece: Hult." |
| 80–90 s | Switch to `/demo` tab | "Live KPIs from this session." |

## After
- Trim in QuickTime (Cmd+T). Export 1080p. Put the file on the desktop *and* in the deck.
